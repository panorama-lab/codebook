# Codebook

Panorama Lab 开发的音视频质性研究编码桌面工具。制定编码手册，在时间轴上标注录音与视频，并将每位编码员的工作保存在本地项目文件夹中。

[English](README.md) · 简体中文

[官方网站](https://panorama-lab.com/codebook) · [下载应用](https://github.com/panorama-lab/codebook/releases) · [问题反馈](https://github.com/panorama-lab/codebook/issues)

## 主要功能

- **编写编码手册。** 创建文本、数值、布尔、单选或多选类型的标注层，记录类别定义、纳入与排除标准、示例、事件边界和判定规则。支持预览与复制生成的手册，以及通过 JSON 导入、导出结构化编码手册。
- **结合原始材料进行标注。** 在同一工作区查看播放器、波形、分层时间轴和编码参考，为音视频添加带时间区间的标注。支持调整边界、循环播放选区、变速播放、撤销与重做。
- **管理多位编码员的工作。** 为同一材料的每位编码员分别保存标注，跟踪完成状态，并在编码手册变更后提示复核已完成的记录。
- **自动转写音视频。** 配置 MiniMax 转写服务，生成带时间戳和说话人标签的文本。点击词语可跳转到对应片段，播放时会高亮当前词语。
- **本地保存项目。** 媒体、编码手册、编码员信息、标注和转写文本均保存在你管理的项目文件夹中。手动编码可离线使用；自动转写需要联网并配置服务商 API 密钥。
- **切换界面语言。** 支持英文、简体中文或跟随系统。切换界面语言不会修改研究材料的原始内容。

## 下载

前往 [GitHub Releases](https://github.com/panorama-lab/codebook/releases) 下载应用。当前提供 **Apple Silicon（arm64）Mac** 版本下载。

打包发布的 macOS 应用会在启动时检查更新，也可通过 **Codebook → 检查更新…** 手动检查。更新下载需要确认，下载后可选择稍后重启安装。

## 快速开始

1. **创建项目。** 为新项目选择名称和保存位置，或通过 **文件 → 打开项目** 重新打开已有的项目文件夹。
2. **制定编码手册。** 添加标注层与类别，描述编码流程，记录编码员应遵循的规则。也可导入已有的编码手册 JSON 文件。通过校验的修改会自动保存。
3. **添加编码员。** 创建本地编码员身份，并选择当前编码员，无需注册账号。
4. **导入材料。** 在材料列表中添加音频或视频。Codebook 会将文件复制到项目中，并检查其是否可以播放。
5. **开始标注。** 打开材料，进入独立的编码窗口。在标注层上拖动以选择时间区间，再双击选区内部创建标注，填写取值后确认。可通过标注列表或时间轴回看、修改已有标注。
6. **标记完成。** 每位编码员的完成状态单独记录。继续编辑会重新打开该记录；编码手册变更后，已完成的记录会被标记为需要复核。

每个“材料与编码员”组合都有独立的编码窗口，可以与项目窗口一起打开，同时查看多个工作区。

## 自动转写

打开 **Codebook → 设置… → 转写**，选择新增服务商，配置 MiniMax API 密钥和 `asr-1.0` 模型。在材料的编码窗口中打开转写文本侧栏，选择自动转写。

音频会分块发送至 MiniMax，服务商可能收取使用费用；重试会启动新的转写任务。失败或取消不会覆盖已有转写。替换已有转写需要确认，旧版本会归档到项目文件夹中。

同一材料的转写文本由所有编码员共享。转写阅读器支持播放定位，目前不提供手动校对或说话人映射功能。说话人标签仅在各个音频分块内有效，不能据此确认不同分块中的人物身份。

## 项目文件与备份

每个项目都是一个包含 JSON 文件和导入媒体的文件夹：

```text
project.json                 项目标识与格式版本
codebook.json                编码方案、标注层与类别
coders.json                  本地编码员身份
assets/                      媒体元数据
media/                       导入的录音、视频与提取的音轨
coding/                      按材料与编码员组织的标注
transcripts/                 转写文本与归档版本
.codebook/                   项目锁与生成的缓存
```

JSON 记录通过原子替换保存，并在相邻的 `.bak` 文件中保留上一版本。请备份整个项目文件夹，以同时保留原始材料和标注。移动或恢复项目之前，请先关闭项目；媒体路径相对于项目文件夹保存。

不要通过多个应用实例或云同步文件夹同时编辑同一个项目。多个本地编码员身份用于分别记录标注，不代表支持实时协作。

## 当前范围

Codebook 正在持续开发中。桌面应用目前专注于音视频编码，暂未提供文本文档编码、分析备忘录、主题分析、编码员比较或 EAF 格式互通功能。

能否播放取决于媒体使用的编解码格式。较大的压缩媒体即使可以播放和标注，也可能无法显示波形预览。编码方案中的规则和标注层关系用于指导编码，目前不会由时间轴自动强制执行。
